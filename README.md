# SHARIFA — демонстрация опроса

Публичная демонстрация интерфейса для согласования с руководителем.

Доступна по адресу: https://sahbanabdulaev445-cell.github.io/sharifa-survey-demo/

Восемь вопросов, мобильная версия, проверка ответов и экран благодарности.
Ответы существуют только в памяти открытой страницы, никуда не отправляются
и удаляются после завершения демонстрации или перезагрузки страницы.
Административная часть и база данных в эту демонстрацию не входят.

В этом репозитории находятся только готовые статические файлы.
Исходный проект хранится отдельно; обновление демоверсии собирается командой
`npm run build:demo`, после чего содержимое `.sites-runtime/github-pages`
публикуется в ветку `main`. Размещение выполняет GitHub Actions.
